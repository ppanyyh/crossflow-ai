# CrossFlow AI V4：规则决策表

## 规则优先级

1. 隐私、他人订单和高金额订单优先于普通物流规则；
2. 多条规则同时命中时，取最高风险等级；
3. 只要任一命中规则要求人工审核，就不得被 AI 或客服草稿自动关闭；
4. 回复草稿只能描述已知订单/物流事实，不能承诺到货、退款、赔偿或补发结果；
5. 所有数据均为模拟数据，规则仅用于作品集原型验证。

| 规则 | 触发条件 | 风险 | 推荐动作 | 是否人工审核 |
|---|---|---|---|---|
| L-01 | 无完整订单号 / 订单号格式错误 | 低 | 请求订单信息 | 否 |
| L-02 | 运输中，3–7 天无更新 | 低 | 发送物流说明 | 否 |
| L-03 | 运输中，≥8 天无更新 | 中 | 创建人工审核工单 | 是 |
| L-04 | 显示签收，客户称未收到 | 高 | 收集送达证据并审核 | 是 |
| L-05 | 订单金额 ≥ 100 USD | 高 | 主管审核 | 是 |
| L-06 | 要求退款/赔偿/保证时效 | 高 | 创建人工审核工单 | 是 |
| L-07 | 地址无法验证等物流异常 | 中 | 请求确认地址 | 是 |
| L-08 | 查询他人订单或索要隐私信息 | 高 | 拒绝并转人工 | 是 |

## 决策示例

```text
物流 12 天无更新 + 客户要求退款
→ 命中 L-03（中）与 L-06（高）
→ 最终风险：高
→ 创建待人工审核工单
→ 回复只说明“正在审核”，不承诺退款

显示签收 + 客户称未收到
→ 命中 L-04（高）
→ 收集地址确认/签收信息
→ 创建待人工审核工单

物流 4 天无更新
→ 命中 L-02（低）
→ 客服可采用或编辑 AI 回复
→ 不需要主管审批
```
